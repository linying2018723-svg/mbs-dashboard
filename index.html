计算公式说明

口径：领星「订单利润」（按下单日归集）· 选定区间内按天求和后重算

① 单件净利瀑布（每卖出一件）

售价 − 商品成本 − FBA发货费 − 平台佣金 − 头程物流 − 广告费 − 退款 − 促销费 − 仓储费 − 其他/预估 + 买家运费 = 单件净利
各项 = 区间内该 MSKU 该项费用总额 ÷ 销量（均摊）。相加精确等于领星净利。

② 各费用项来源（领星字段）

商品成本采购成本 − 退货可再售回冲 purchase_costs + return_*_purchase_costs
FBA发货费FBA 配送费 fulfillment_fee
平台佣金销售佣金 + 其他销售费 selling_fee + selling_other_fee
头程物流logistics_costs
广告费SP+SB+SD 花费 spend
退款退款额 + 库存赔偿 refund_amount + inventory_credit
促销费promotion_discount + promotion_fee
仓储费月仓储 + 长期仓储 total_stock_fee
其他/预估预估费+调整+其他+残差
买家运费买家运费（收入，加回）shipping_cost

③ 衍生指标

主SKU 净利= 旗下所有 MSKU 净利之和
净利率= 净利 ÷ 销售额
ACoS= 广告费 ÷ 广告销售额
退款率= 退款额 ÷ 销售额

④ 标红阈值

净利/净利率< 0
ACoS> 25%
退款率> 12%
商品/FBA/佣金/物流/仓储 占售价> 45% / 35% / 18% / 10% / 5%
口径提醒：① 广告/退款为区间总额÷销量的均摊值,非逐单;② 广告按花费日、退款按退款发生日归集,与销量分母有时间错配;③ USD 为按≈6.79 估算汇率折算(领星实时汇率有小差,CNY 为准);④ 利润为下单日口径,非财务结算口径;⑤ 数据为按需刷新,当前截至页面顶部日期。

库存风险 / 可售天数 说明

可售天数 DOS

DOS = 领星 historical_days_of_supply = 现有可售库存 ÷ 历史日均销量

断货判断（全链路 · 主SKU 为准）

FBA可售=0 时,再看在途(已发货+计划中+接收中);有在途就是"已备货",不是真断货。
真断货FBA可售=0 且 在途=0 —— 正在损失销售,需紧急补货
断货·已备货FBA可售=0 但 在途>0 —— 补货在路上,盯到货即可
断货预警FBA可售>0 且 0 < DOS < 15 天 —— 在卖、快卖完
低风险15 ≤ DOS ≤ 90 天 —— 健康
中风险90 < DOS ≤ 180 天 —— 开始积压
高风险DOS > 180 天 —— 严重积压、占压现金
呆滞有可售库存但近期 0 销量(DOS=0) —— 死库存,该清仓/移除

全链路数量

FBA可售afn_fulfillable_quantity
在途已发货 + 计划中 + 接收中 afn_inbound_shipped + working + receiving
预留afn_reserved_quantity
说明：库存为当前时点快照,主SKU 风险取其下 MSKU 的最紧急档。国内仓(上海/义乌)库存暂未接入(领星 MCP 未开放该数据)。风险按货值衡量。DOS 用领星历史口径。
